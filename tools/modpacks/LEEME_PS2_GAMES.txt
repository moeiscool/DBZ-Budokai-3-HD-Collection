PUT YOUR COPIES OF THE PS2 GAMES HERE (to import characters)
============================================================

The launcher's importer only detects them if they have these names:

- Budokai 1:  an .iso whose name contains "Budokai (Europe)" or "Budokai (USA)"
              example: DragonBall Z - Budokai (Europe) (En,Fr,De,Es,It).iso
- Budokai 2:  an .iso whose name contains "Budokai 2"
- Infinite World:  a FOLDER whose name contains "Infinite World" with the disc
              extracted inside (it must have USR\DATA_CMN.AFS)
- Budokai 3 Greatest Hits (PS2): a "Budokai 3 Greatest Hits (USA)" folder with the disc
              extracted (used for the base moves of the Budokai 1 characters)

ISOs are read as they are: no need to extract them.
