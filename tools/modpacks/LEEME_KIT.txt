DBZ BUDOKAI 3 HD COLLECTION - MODDING KIT (v1.4.0)
==================================================

All the port's modding tools, now with their own window (DBZ3 HD Mod Kit): create and
import new characters (Budokai 1, Budokai 2, Infinite World and community models), own
capsules, voices and yells, textures, model swap and the rest of the converters. No
need to open any console.

WHAT YOU NEED
- DBZ Budokai 3 HD Collection v1.4.0 or later, with the game data in a FOLDER.
- Python 3.11 or later (free: https://www.python.org/downloads/). When installing it,
  tick the "Add python.exe to PATH" box.

INSTALL (4 steps)
1. Close the game.
2. Copy EVERYTHING in this ZIP into the game folder (where dbz3.exe and the us folder
   are). "mod center hd" and "awo_tools" must end up next to dbz3.exe.
3. Double-click "instalar_requisitos.bat" (it installs numpy, Pillow and scipy, the
   libraries the tools use; only needed once).
4. Double-click "DBZ3_ModKit.bat": the kit window opens.

THE KIT WINDOW (DBZ3_ModKit.bat)
- BASIC mode: big, guided cards. Start with "Check installation" (all green) and then
  choose: My mods, Import character, New characters, Create with my models, Textures,
  Model swap or Help and community.
- ADVANCED mode (top right): tabs with ALL the options of each tool, the full log, the
  paths and the "Tools" tab with every script of the kit.
- Language: ES / EN, top right.
- It does the same as the launcher's modding tabs (same tools and same arguments): you
  can use both. New characters are added when you press PLAY.
- Before editing a mod's file, a copy is saved in "modkit_backups".

IMPORTING CHARACTERS FROM OTHER GAMES
- Put YOUR copies of the PS2 games in the "ps2_games" folder (read ps2_games\LEEME.txt).
- In the kit window: "Import character": pick the game, search the character, check the
  name and press Import (or in the launcher: "New characters" > "Import a character
  from another game"). It is added when you press PLAY.
- Community models (.amb or .amo + .amt) are looked for in "modding resources".

CONTENTS
- DBZ3_ModKit.bat  opens the kit window (double-click)
- mod center hd\   tools (roster_build, import, capsules, voices, yells, textures,
                   modkit_gui...) and tools\ (Xbox 360 LZX compression)
- awo_tools\       format converters (PS2 -> HD, Budokai 1, heights, name banners,
                   portraits...)
- modding resources\  community lists (capsules, IDs, voices) used by the importer
- docs\            guides (how to make mods, textures, model swap) and docs\formatos

It contains no files from any game: always use the ones from your own copies.

The kit runs on Windows. Mods made with it can also be copied to the experimental PS5
build (/data/dbz3/mods on the console; see docs/PS5.md in the source repository).
